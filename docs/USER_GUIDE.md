# 用户指南

## 界面结构

Go 工作流设置分为六个页面：

| 页面 | 用途 |
| --- | --- |
| 工作流 | 创建、复制、删除和排序工作流 |
| 面板库 | 选择当前工作流要显示的 Blender N 面板 |
| 脚本模块 | 管理当前工作流中的脚本模块 |
| 脚本库 | 保存和复用独立脚本 |
| 预设 | 导入导出 `.gwpreset` |
| 全局 | 面板同步、提示、内存和恢复选项 |

## 工作流

工作流是一组面板和脚本模块的组合。切换工作流时，GoWorkFlow 会更新当前编辑器空间中的面板显示范围，并保留各工作流独立的模块配置。

建议为不同任务建立独立工作流，例如：

- 建模与形态键检查
- ARKit/MMD 表情处理
- 面捕采集与回放
- 渲染和批处理

默认工作流用于显示基础面板，不建议把所有第三方面板都永久加入默认工作流。

## 面板库

面板库会扫描当前 Blender 环境中可用的侧边栏面板，并按插件来源和面板层级分组。

常用操作：

- 搜索：按面板标题、插件或分类查找。
- 加入/移除：点击面板组或单个面板。
- 排序：在当前工作流区域调整面板组顺序。
- 刷新：插件安装、卸载或升级后重新扫描。
- 缺失面板：目标插件未安装或面板 ID 已变化时显示。

缺失面板记录不会自动删除其他工作流内容。确认不再需要后，再使用清理按钮移除对应记录。

## 脚本模块

每个脚本模块属于当前工作流，可以使用：

- 内嵌脚本内容
- Blender Text 数据块
- 外部 `.py` 文件
- 自定义模块面板

脚本模块的基本入口是：

```python
def run(context, scene, workflow, module):
    return {"FINISHED"}
```

如果模块需要显示自定义 UI，可以实现：

```python
def draw_panel(layout, context, scene, workflow, module, panel_api, module_state):
    layout.label(text="Hello GoWorkFlow")
```

运行脚本前，应在模块面板中确认脚本路径、目标对象和自定义参数。

## 脚本库

脚本库适合保存可跨工作流复用的 `.py` 脚本。保存当前模块时，脚本源文件会写入脚本库目录，并在条目中记录路径。

建议：

- 为脚本设置清晰且稳定的名称。
- 将外部依赖写入脚本说明。
- 迁移项目时检查脚本路径是否仍然有效。
- 不要把本地自动生成的 `_imported_presets` 当作脚本库备份。

## 预设

### 导出

在预设页面勾选需要导出的工作流，再点击导出。导出的 `.gwpreset` 包含：

- 工作流名称和说明
- 面板匹配信息
- 脚本模块配置
- 相关脚本源文件
- 脚本库条目
- 部分模块配置和说明

### 导入

预设导入分为两步：

1. 载入预设：读取包内容并列出其中的工作流。
2. 导入选中工作流：将当前选择的工作流添加到当前编辑器空间。

这样可以先查看预设内容，再决定导入哪个工作流。导入过程中如果脚本或模块失败，当前导入会回滚，不会故意覆盖现有工作流。

### 跨机器迁移

面板记录只保存匹配信息，不会把第三方插件打包进预设。目标 Blender 必须安装对应的第三方插件，才能恢复全部面板。

## 内置形态键工具

内置脚本库包含以下方向的工具：

- ARKit 形态键合成到 VRM/MMD 目标集。
- AA/OH/CH 和 VRChat/MMD 口型生成。
- 形态键空键鉴定。
- 形态键实时采集、投射和回放。

形态键工具通常要求目标网格已经存在形态键。运行前先确认目标对象、Basis、源形态键名称和目标集配置。

## 状态和缓存

GoWorkFlow 会在 Blender 用户配置目录保存全局工作流状态，并在预设导入时生成脚本、配置和说明资产。

正常情况下不需要手动管理这些文件。排错时重点保留：

- `go_workflow_global_state.json`
- `go_workflow_global_state.json.bak`
- Blender 控制台或崩溃日志
- 触发问题的 `.gwpreset`
